# 老黄掏出超级 CPU，带领英伟达重新定义 Windows 电脑

\#科技热点 #人工智能 #英伟达 #CPU #科技与狠活

太炸裂了！就在刚刚，英伟达的老黄重新发明了我们用了四十年的个人电脑。他们将把 Windows 电脑从一台人类操作软件的机器变成一台 AI Agent 自己干活的机器。

过去我们用电脑是打开 Word 写文档，打开 PS 修图，打开 PR 剪视频，打开浏览器查资料，本质上是人在电脑前点来点去，软件只是工具。但老黄这次让人与电脑的交互逻辑彻底反转，过去是人来操作软件，而未来将用 Agent 来替你完成所有任务。

为了让这个数字员工真的跑起来，英伟达重新定义了 CPU。传统 CPU 是给人类用的，人点一下鼠标，多等几秒钟加载，其实并没有那么敏感。但 Agent 不一样，它要不停地调用模型，提取文件，访问数据库，运行代码，打开软件，它生活在一个纳秒级的世界里，每慢一步，整个任务都会卡住。

所以英伟达做了 Vera CPU，它不是为了让你多开几个网页，而是为了让 Agent 在数据中心里低延迟的调度模型，工具，数据库和记忆系统。这意味着 CPU 不只是电脑的大脑了，而成为了 AI Agent 的调度中枢。

而接下来就是真正和我们每个人都相关的，老黄直接在台上掏出了 RTX Spark 超级芯片，宣布英伟达将重新定义个人电脑。它把 Blackwell RTX GPU，二十核 Grace CPU，128GB 统一内存和完整的 NVIDIA AI 和图形软件栈塞进了一台轻薄的 Windows 笔记本里。

相比普通 PC，它最高拥有 1 Petaflop AI 性能，可以本地运行 120B 参数、100 万 Token 上下文的大模型，还能剪 12K 视频，生成 4K AI 视频，渲染 90GB 级别的超大三维场景。最关键的是安全，英伟达和微软一起给 Windows 做了一套智能安全底座。

通过 Windows 安全基元和 NVIDIA OpenShell Agent，现在 AI Agent 可以在你的主力电脑上安全运行。这意味着 AI Agent 不再只是网页里的聊天框，而是第一次有机会安全地进入你的电脑系统，调用本地文件和专业软件。

现场这个建筑设计案例就很典型，过去设计一套房子要查资料，画草图，建模型，做布局，再导入 Blender 加材质，打光，渲染。但现在 AI Agent 可以理解草图，风格版和文字需求，自己打开犀牛建模，规划房间，墙体，门窗和动线，发现了错误还能自动修正。

最后再导入 Blender，调用生成 AI，直接生成照片级的效果图。Adobe 这些软件大厂也迅速跟进，Photoshop 和 PR 已经在为 RTX Spark 重新优化，不只是速度最高提升了两倍，而是开始变得更适合 Agent 调用。

过去三十年 PC 世界的底层联盟叫 Wintel，Windows 加英特尔。但现在英伟达想建立的是 Windows 加 NVIDIA AI。这不只是英伟达来抢一个 CPU 的生意，他是想把数据中心里的 AI 计算体系搬到每个人的桌面上。

如果说苹果 M1 当年重新定义了 Mac，那英伟达这次想重新定义的是整个 Windows PC。过去电脑是人类的工具，未来电脑可能会变成一个会思考，会调用工具，会替你干活的数字员工，所以 PC 行业真正的战争今天才刚刚开始。
