智能体流水线都来了，外滩大会一探究竟 #2026 外滩大会 #人工智能 #科技热点 #Agent #具身智能

这不是黄总吗？你也来外滩大会了？是的，非常开心。开个玩笑，这并不是真的老黄，而是最近因为模仿黄仁勋走红的黄忠勋。既然黄总都来了，干脆带他去看一座特别适合他的工厂。只不过这座工厂不造 gpu，不造手机，专门造 ai。 员工，这里是外滩大会蚂蚁数科展台。既然今天我智能体工厂厂长马甲加身，那就带你们一探究竟。首先你知道为什么智能体和工厂能联系上去？近两年我们见过太多 agent 了，会写代码的，做客服的，做风控的，一个比一个聪明。但你知道吗？当企业真正把几十上百个 agent 塞进业务以后，才发现麻烦才刚开始。谁给他们分工？谁能碰数据？谁负责审批？上下游怎么接？一个 agent 很聪明和一千个 agent 能不能像一个组织一样工作，根本是两回事。 以前大家一个个捏 agent，外靠人把任务传来传去，本质上还是手工作坊。所以今天真正缺的是如何把这些智能体做成一条流水线，岗位、权限和生产制度。而现场的这条生产线就是这么设计的。

• 先生产单个智能体，再把行业 knowhow 知识库和 skill 封装进去，组成可以直接上岗的数字专家。
• 最后再让多个专家自己拆任务，协助交付结果。

蚂蚁数科在他们的智能体工厂里面内置了两百多个岗位，技术的专家六百多个 skill。这思路已经不是给员工一个 ai 工具了，而是直接把企业从工具思维推到了岗位思维。 对了，我今天还真下场当了一回工人。你看，当我带上这个 vr 设备以及 ego 第一视角采集设备，把产线上的分拣、质检这些动作完整做了一遍，我眼睛看哪里，手怎么抓，动作顺序怎么走，全部都变成了具身智能可以训练的数据。这个体验其实挺有意思，因为企业真正值钱的东西很多，压根不在 ppt 和聊天记录里，它藏在银行的信用风控、能源的交易调度，甚至老师傅十几年形成的动作和判断里。 ai 真正进入产业，学的就不只是人怎么说，而是人到底怎么干活。但越往真实业务里走，光聪明还远远不够。一个 agent，它代表谁？谁授权它调用数据？干过什么能不能追溯？未来两个公司的 agent 真开始互相谈业务，又凭什么相信对方？所以蚂蚁过去积累的区块链、数字身份、隐私计算、安全风控，到了这个阶段反而都重新变成了底座。 所以逛完整个展台，我认为模型时代大家拼的是 ai 的智商，而 agent 时代则开始要拼一家企业组织 ai 的能力了。真正的生产力革命并不是人类突然拥有一千个 agent，而是这一千个 agent 终于能像一家真正的公司一样开始工作了。
