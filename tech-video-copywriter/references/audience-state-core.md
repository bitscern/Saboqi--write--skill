# 逐句用户感受核心：先设计感受，再设计文字

这是本 Skill 在事实边界与发布红线之下的最高优先级逐句表达规则。它只在选题、材料、结构、固定开头、品牌立场、情绪强度和爆款公式已经确定之后生效，用来决定每一句怎样把既定内容写得能被观众感受、理解和记住。

它不参与选择传播方向，不否决或覆盖上游内容规则，也不要求固定开头、品牌立场、情绪强度和既有爆款公式服从 A→B。上游规则决定“这一条讲什么、怎么组织、情绪开到多大”；本规则只负责“其中每一句怎样对观众产生作用”。

本规则吸收自李叫兽《为什么你会写自嗨型文案？》的方法框架，并针对科技资讯短视频改写为逐句约束；只继承写作逻辑，不复制原文案例或措辞。

## 每句话的工作对象不是文字

写每一句时，设计的是观众的感受与理解变化，不是文字本身。不要先问“怎样把这句话写得更华丽、更高级、更有气势”，先问：

- 观众听到这句之前，脑中已经有什么？
- 这句话承担的是识别、理解、感受、记忆还是行动中的哪一个任务？
- 听完这一句后，观众应该具体多知道、看见或感受到什么？
- 怎样用最低理解成本完成这一个小推进？

像设计灯光而不是只设计灯泡一样，写产品相关句子不能只围绕名称、参数、功能和作者评价发挥创意，要把既定信息写成观众能够看见、得到、摆脱、比较或转述的东西。

## 逐句 A→B

把观众听到某句话之前的状态记为 A 点，听完这句话之后的状态记为 B 点，这句话的有效作用是 `B-A`。整篇口播是这些微小状态变化连续相接，而不是另设一套上游内容结构。

写关键句或审稿时，使用最小逐句检查：

```text
A 点：听到这句之前，观众已经知道和感受到什么
句子任务：这句负责解释、描绘、证明、连接利益、放大情绪还是落下判断
B 点：听完这句之后，观众新增了什么具体认识或感受
B-A：这句不可替代的推进是什么
```

A 点不能默认成作者、公司员工、行业专家或粉丝的知识状态，除非上游规则已经把他们确定为核心观众。逐句默认用既定核心观众在上一句话结束时真实拥有的信息来校准，不重复讲他已经知道的内容，也不跳过他尚未获得的理解。

B 点不是作者想宣布的口号，也不是越宏大越好。一句话通常只完成一个小跃迁，例如：

- 不知道这是什么 → 一句话看懂对象与用途。
- 知道功能 → 看见它完成了什么具体动作。
- 听到参数 → 感受到这个数字造成的实际差异。
- 听到事实 → 明白它与自己的利益、关系或好奇心有什么连接。
- 只有模糊情绪 → 获得一个能复述的具体判断。

句与句之间要接得上：后一句的 A 点应当包含前一句已经完成的 B 点。既有结构和爆款公式保持不变，但不能在具体表达中默认观众凭空获得了中间知识。

## 用既定受众校准每句话

核心受众、传播方向和市场阶段由上游规则决定。本规则不重新选择它们，只据此控制一句话需要解释多少、可以省略什么以及使用哪种观众熟悉的参照物。

- 对已经了解产品的人，一句话可以直接交付差异与选择理由。
- 对尚未认识品类的人，同一个意思要先让他看懂对象和用途，不能用行业内部简称代替解释。
- 对不熟悉技术名词的人，把完成态动作或生活结果写进句子，再接名称与原理。
- 对熟悉题材的核心圈层，可以减少基础解释，直接写反常识、代际变化、利益冲突或新证据。

场景会改变一句话的理解入口。上游已经确定要使用某种生活处境时，句子应调用该处境里真实存在的感受与物体，不能为了“用户视角”再给既定内容硬贴另一种焦虑。

## 把功能写成可感知结果

抽象功能、参数和形容词不能自动形成感受。写句子时，优先使用这条翻译链：

```text
产品能力／参数
→ 完成了什么具体动作
→ 人物、物体或环境发生什么状态变化
→ 对既定核心观众意味着什么
```

“性能强、体验极致、开启未来、行业领先”只表达作者评价，不能让观众获得产品特色、差异或优势。要把同一内容写成具体物体、数量、动作、时间、关系或后果。

情绪词、品牌崇拜和宏大判断的强度由上游规则决定，本规则不降低它们；只要求承载这些选择的句子有观众可以感受到的对象，不能用形容词替代内容。

## 五个逐句硬测试

标题、封面短句、钩子和正文中的每一句至少通过以下测试：

1. **陌生人测试**：以既定受众的知识水平，他能否知道这句在说谁、什么或哪件事？
2. **画面测试**：听到这句，脑中能否出现人物、物体、动作、场景、数量或结果？若只剩抽象词，改写。
3. **利益测试**：这句若承担利益连接，是否说清与观众的钱、时间、工作、身体、家人、能力、选择、好奇或身份投射的关系？纯奇观可以只交付“值得看见或知道”的结果。
4. **口碑转述测试**：一个正常人会不会把这句话自然讲给朋友听？若只能出现在公司海报或作者自我感动中，改写。
5. **记忆测试**：这句留下的是具体画面、数字锚点、动作结果或因果判断，还是只有“它很好、很强”的评价？

这些测试只修改句子的写法，不据此更换已经确定的开头形式、品牌立场、情绪强度、结构或爆款公式。

## 句内信息服从观众理解

本规则不改整篇结构，只处理一句内部先说什么、后说什么：

- 陌生名词与解释同时出现时，优先让观众抓住熟悉的物体、动作或结果。
- 参数与意义同时出现时，把数字立即接到它证明的能力或结果上。
- 判断与依据同时出现时，让两者的因果关系清楚，不能只靠语气连接。
- 一句话有多个互相竞争的信息时，拆成相邻短句，但不改变它们在既有结构中的位置。

## 禁止逐句自嗨

出现以下情况时，不得用更华丽的修辞补偿句子没有作用：

- 没有特色、差异与利益，只反复说“好、强、领先、颠覆”。
- 作者掌握背景知识，默认观众也知道产品、人物、术语和前史。
- 结论只让作者显得深刻，却没有增加事实、因果、利益关系或具体后果。
- 句子读起来工整高级，却无法生成画面、无法自然转述、无法留下具体记忆。

这不降低或限制上游已经确定的修辞、情绪、节奏、玩梗和品牌粉丝立场。只要求每一句仍然有清楚作用，不能让文字技巧替代句子应交付的信息或感受。

## 逐句逆向验收

交付前依次检查：

1. 这句话之前，观众实际知道什么、知道到什么程度？
2. 这句话具体新增了什么画面、理解、利益、情绪或判断？
3. 下一句话是否从这个新增状态继续，而不是突然假设更多背景？
4. 删掉这句话，观众的感受或理解是否完全不变？若不变，删除。
5. 把句子里的产品名换成任意品牌后仍然成立吗？若成立且这句本应表达特色，说明仍然空泛。
