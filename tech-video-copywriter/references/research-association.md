# 事件关系网研究法

本文件用于实际选题、传播方向和成稿前的资料研究。目标不是给正文塞入更多新闻，而是让当前事件进入一张更大的时间、产业、人物和人机关系网，使判断具有阅历、纵深和可传播性。

案例学习不执行本流程。用户只提供正反例训练 Skill 时，仍按 `case-update.md` 跳过事实搜索。

## 核心原则

专业感不来自知道更多孤立事实，而来自看见事实之间的关系：一项新能力接上了什么前史、终结了什么旧阶段、与哪些同期事件共同出现、在另一行业发生过什么同构变化，又会把谁的角色和利益推向下一步。

搜索必须同时完成两项任务：

1. **事件核研究**：确认当前事件发生了什么，哪些事实能够支撑选题。
2. **关系网研究**：主动离开当前发布页，寻找能够增加时间尺度、因果、反转、人物连续性或趋势证据的外部素材。

强制的是关系网搜索，不是正文一定引用许多事件。关联候选都弱时可以不用，但不能因为用户资料已经完整就跳过联想。

## 两轮搜索

### 第一轮：建立事件核

优先从原始发布、演示、论文、系统卡、当事人原文和公司资料中确认：

- 发生了什么，为什么是现在。
- 最强的完成态动作或结果是什么。
- 相比上一代真正新增、删除或改变了什么。
- 官方怎样定位这次变化。
- 哪些限制、安全问题和比较条件会影响核心判断。
- 哪条事实最能支撑本条视频的唯一命题。

第一轮只解决准确性和基本新闻价值，不能因为资料足够写一篇产品摘要就停止。

### 第二轮：扩散关系网

先用一句话写出暂定中心判断，再围绕“什么能证明、扩大、反转或历史化这句话”设计查询。中文资料负责发现本地讨论与传播语境，英文资料负责追原始信息、历史材料、当事人原文和专业背景；不要只改写同一个产品关键词反复搜索。

每轮查询应改变关系维度，例如从产品名切换到能力、被移除的人类角色、历史节点、人物旧言或相邻行业。搜索结果仍然只围绕当前主命题收敛。

## 八条联想射线

实际研究时快速扫描八类关系。抢时效时至少探索其中三类，优先时间前史、同期共振、跨行业同构和反面证据；标准产品更新全部扫描。

### 1. 时间前史

寻找上一代产品、同一能力第一次出现、早期失败或不成熟版本、公司几年前的路线判断以及当事人过去的预测。它负责把新品变成一段长期伏笔的完成，而不是突然出现的功能。

查询方向：

```text
[产品／能力] previous generation first demo timeline
[公司／人物] prediction interview [能力]
[能力] early attempt failed limitation
```

### 2. 历史回环

寻找过去一次相似的技术角色变化：PC、互联网、智能手机、云计算、自动化或其他技术曾删除什么旧环节，人们当时怎样判断和误判。它负责提供具体时间尺度，不能只借“工业革命、iPhone 时刻”等大词制造气势。

### 3. 同期共振

寻找同一天、同一周或同一发布窗口中，另一家公司、产品或行业是否出现相同方向的变化。同期只能证明多个信号正在共同出现，不能自动写成彼此导致。

查询方向：

```text
[日期范围] [能力／角色变化] launch announcement
[同一人类角色] autonomous release [日期范围]
[趋势命题] company launch this week
```

### 4. 跨行业同构

不要只搜索同类产品，而要搜索同一种结构变化。例如 AI 接管鼠标，可以联想汽车删除司机、工厂删除操作员；模型参与训练模型，可以联想芯片设计、软件生成或机器人学习中的相同闭环。

关系成立的标准不是“都属于 AI”，而是“都在转交、缩短或删除同一种人类角色”。

### 5. 人物与公司旧账

寻找创始人过去的原话、公司长期坚持或反对的路线、今天是否兑现或推翻以前的判断，以及竞争对手曾如何评价这条路线。它负责建立人物和公司的连续人格，不为了热度随意挂名人。

查询方向：

```text
[人物／公司] said predicted [核心能力]
[公司] strategy history [技术路线]
[竞争对手] response comment [产品／路线]
```

### 6. 上游原因

继续追踪哪种芯片、数据、能源、成本、训练方法、供应链或产品设计使事件今天成为可能；寻找刚刚被移除的长期瓶颈。它负责回答“为什么偏偏是现在”。

### 7. 下游后果

寻找已经出现的用户行为、工作流、组织调整、商业投资、价格变化和职业动作。明确谁会先获利、谁会先被迫改变。优先使用已经发生的动作，推演与已发生事实分开。

### 8. 反面证据与新矛盾

寻找更强、更安全、更便宜或更自动之后出现的限制、责任、控制、可理解性和真实任务落差。它负责制造反转和可信度，不为了“客观”机械加入无关批评。

查询方向：

```text
[产品／能力] system card limitation safety evaluation
[核心宣称] independent test failure criticism
[能力] real world limitation benchmark gap
```

## 关联素材卡

第二轮搜索后先建立候选池，不直接把搜索结果写进正文。每项候选至少记录：

```text
关联事件：具体事件、人物、旧言或历史节点
关系类型：前史／回环／同期／同构／上游／下游／反转
关系句：它与当前事件共同说明什么
叙事职能：钩子／对照尺／第二证据／转折／结尾尺度
信息增量：增加了什么事实、因果、时间尺度、情绪或谈资
理解成本：能否在一至两句话内让普通观众听懂
来源等级：原始来源／权威二手／编辑推演
主要风险：跑题、假因果、抢主角、限定条件或画面依赖
```

“关系句”是强制字段。无法用一句话解释两件事共同证明什么，通常说明关联只是关键词相似或作者在炫耀见识。

## 五道筛选门

外部关联进入方向卡或正文前必须同时满足：

1. **真关联**：双方共享同一种机制、原因、角色变化或后果，不只是同一行业或关键词。
2. **强主线**：它继续证明本条视频的唯一核心判断，没有开启另一条同等重要的新选题。
3. **低成本**：普通观众能在一至两句话内理解它与主事件的关系。
4. **有增量**：删除后，正文的意义、可信度、惊奇、因果或时间尺度会明显下降。
5. **可核实**：关联事件本身有可靠来源；事实、引语和编辑推演没有混写。

再做两个反事实测试：

- 若把关联对象换成任何一家公司的通用新闻，结论仍成立，说明它缺乏专属性。
- 若删掉关联后文案几乎没有损失，说明它只是装饰。

## 关联素材的五种叙事岗位

- **钩子**：用同期共振、旧预测兑现、历史节点终结制造“这不是孤立新闻”的观看缺口。
- **对照尺**：用过去做不到、成本极高或需要更多人完成的事件衡量今天的变化。
- **第二证据**：主产品证明一次，另一公司或行业再证明一次，把单点能力升级成趋势。
- **反转**：用限制、安全信号、真实任务落差或历史教训改变单向情绪。
- **结尾尺度**：用具体历史回环、产业迁移或人机角色变化完成最终判断。

每个被选中的关联只承担一个主要岗位。它必须在出现后立即说明与主事件的关系，不能让观众自行猜测为什么突然换新闻。

## 使用量与时长

- 30–60 秒通常只保留一至两个最强外部关联。
- 90 秒可以保留两至四个，但仍需服务同一主命题。
- 外部素材不能比事件核更长、抢走主角或迫使观众记住多套背景。
- 同期发生不等于存在因果；跨行业相似不等于技术路径相同。
- 不得为了表现阅历，反复套用工业革命、iPhone 时刻、时代拐点或固定名人。

要增加的是搜索广度和关系质量，不是正文中的名词数量。

## 研究强度

### 抢时效快讯

- 完成事件核搜索。
- 至少探索三类外部关系。
- 找到一个通过五道门的高价值关联即可开始写。
- 若没有强关联，保留单事件路线，不为凑素材错过窗口。

### 标准产品更新

- 快速扫描八类关系。
- 形成至少六个不同关系类型的候选，而不是六条同类新闻。
- 筛出两至三个进入方向设计，正文通常只保留一至两个。

### 90 秒深度稿

- 在八类扫描之外继续追踪上游原因和下游后果。
- 至少形成一条“过去 → 当前突破 → 下一步后果”的时间链或产业因果链。
- 外部素材按因果或时间推进，不能横向罗列。

## 停止条件

满足以下条件即可停止扩散搜索并进入方向设计：

- 事件核关键事实已有原始来源支撑。
- 已探索与时效匹配的关系类型。
- 至少找到一个能明显增强主命题且通过五道门的外部关联，或已确认所有候选都会跑题。
- 再增加搜索只产生同类重复信息，没有新的叙事岗位。
- 所有拟进入正文的事实、引语和比较都能追溯来源。

不要为了“研究充分”错过新闻窗口，也不要把没有找到强关联误判为研究失败。

## 写作前最终检查

1. 这件事之前谁尝试过，今天跨过了什么旧边界？
2. 哪个历史节点能提供真实尺度，而不是万能类比？
3. 同期是否有另一事件证明相同变化？
4. 另一行业是否正在删除或转交同一种人类角色？
5. 哪个旧预测、旧失败或公司旧路线在今天形成回环？
6. 哪项外部素材能制造反转，而不是继续吹捧？
7. 最终选中的关联分别承担什么叙事岗位？
8. 它们能否用一句关系句共同回到唯一主命题？
9. 是否误把同期写成因果、把类比写成事实或把推演写成已经发生？
10. 如果只能保留一个外部关联，哪一个最值钱？
