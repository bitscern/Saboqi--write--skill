# 发布红线

本文件是所有拟发布内容的强制审查表。清单中的词只用于内部匹配，不得原样复制进标题、钩子、口播、封面、评论引导、发布配文、标签或其他面向观众的文字。审查时同时识别完整词、变体、谐音、拆字、字母缩写、暗语、表情或画面暗示，不得用任何绕过形式保留原意。

## 禁止内容

| 类别 | 细分 | 禁止内容 |
| --- | --- | --- |

| 国家政治 | 敏感事件 | 历史政治事件、地缘政治冲突、暴力恐怖活动、敏感社会负面事件及其延伸 |
| 国家政治 | 禁限术语 | 翻墙、VPN、科学上网、代理服务器、外网、魔法、机场、节点，以及涉及体制攻击的词汇和变体 |
| 军事军队 | 行动与器械 | 枪、攻打、开战、侵略 |
| 金融投资 | 投资动作 | 荐股、选股、必涨、稳赚、理财建议、定投、抄底、回升 |
| 金融投资 | 币圈相关 | 虚拟货币、比特币、BTC、挖矿、交易所、ICO、数字藏品、NFT、Web3、USDT |
| 封建迷信 | 玄学词汇 | 算命、看相、测字、风水、转运、辟邪、做法事、占卜、塔罗牌 |

| 性别／群体对立 | 贬损标签 | 女拳、下头男，以及针对特定性别、地域、年龄、职业或其他群体的贬义标签 |
| 血腥暴力 | 伤害与血腥 | 杀人、吃人、血、尸体、虐待、自残 |
| 引流 | 非合作企业 | 未确认为当前合作方或授权商单对象的国内企业名称、品牌、账号、标识及其导流信息 |
| 引流 | 平台名称 | 在某平台的拟发布内容中点名竞争平台；例如在抖音文案中提小红书，或在小红书文案中提抖音、快手等其他短视频平台 |

## 执行方式

1. 先判断选题核心是否落入上述语义类别。核心事实属于红线时，不靠替换字词继续写；直接判定为不适合发布，并提供不涉及该红线的备选科技角度。
2. 原始资料、用户初稿、引用、产品名、人物原话或来源标题中已有的红线词也不保留。事实转述不构成豁免。
3. 对可安全保留的非核心信息，优先整句删除；必须保留时使用不指向原禁止概念的中性表达，不使用易被还原的替换词。
4. 跨平台交付时，每一组发布配文和标签单独审查。不在单个平台的可复制文案中列出其他平台名；交付文档中用于区分版本的编辑标签不属于拟发布文案。
5. 完稿后依次审查：精确词面 → 变体与谐音 → 隐喻和语义 → 人物或画面暗示 → 跨平台引流。任一项不通过就重写相关字段并重新完整检查。
